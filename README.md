# AugmentedMD

Landing page for open-source clinical tools designed to help doctors navigate the post-AI digital world.

**Created by Michael Gorin, MD** — Academic urologist at Mount Sinai focusing on use of technologies (AI-based and conventional) to improve patient safety, operational efficiency, and physician effectiveness.

## About

AugmentedMD serves as a central hub showcasing practical, privacy-first tools for modern medical practice. All tools featured here are open source and free to use, modify, or improve upon.

## Features

- **Responsive Design** - Works seamlessly on all devices
- **Clean Interface** - Professional medical/academic aesthetic
- **Tool Showcase** - Grid layout highlighting available and upcoming tools
- **Single File** - All HTML, CSS, and JavaScript in one standalone file

## Current Tools

### Available Now
- **[PHI Scrubber](https://github.com/gorin-research-repo/phiscrubber)** - Remove protected health information from clinical text with fully offline detection

### Coming Soon
- Clinical Note Assistant
- Evidence Navigator
- Secure AI Gateway
- Differential Diagnosis Aid
- Patient Communication Helper

## Usage

Simply open `index.html` in any modern web browser. The site is fully functional without any build process, dependencies, or server requirements.

## Deployment

This is a static site and can be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service
